# ok-dna-mod

这是基于 [ok-duet-night-abyss](https://github.com/BnanZ0/ok-duet-night-abyss) 修改的 ok-dna-mod 版本。

> 推荐使用 BetterGI 的桌面分身，否则容易影响技能释放。
> 按键设置推荐都设为键盘按键，云游戏用鼠标按键可能会出问题。

## 下载安装

[![下载完整安装包](https://img.shields.io/badge/下载-完整安装包-2ea44f?style=for-the-badge)](https://github.com/YianBu/okdna_modified/releases/latest/download/ok-dna-mod-win32-China-setup.exe)

> 下载后双击运行，按照安装器提示完成安装即可。
